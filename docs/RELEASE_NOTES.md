# Istaroth 1.0 — First Public Release

**Your Companion Throughout Time!**

Istaroth is an independent, free, open-source Windows desktop companion for Genshin Impact.

### Features
- Automatic HoYoLAB Original Resin synchronization and recovery estimates
- Full Main Widget and compact Mini Resin Widget
- Three independently customizable wallpaper regions: Main, Resin Card and Mini
- Wallpaper live previews and separate adjustments
- Nine illustrated region themes in the Style customization gallery
- Tray integration, Windows autostart, reminders, quiet hours, and local history
- Account, daily, exploration, combat and TCG panels when available

### Installation
Download **Istaroth_Setup_v1.0.exe** and run on Windows 10 or 11 (x64). On first install the setup may download the official Electron runtime, which is SHA-256 verified. Close previous Istaroth/Teyvat Pulse tray instances before upgrading.

Local profile data intentionally remains under the legacy `%APPDATA%\Teyvat Pulse` path to preserve sign-in and settings.

### Important
The installer is **unsigned**. SmartScreen may warn about an unrecognized publisher; that is not equivalent to an antivirus malware detection. The Windows installation and live HoYoLAB integration have not been verified on every PC. Not affiliated with or endorsed by HoYoverse or Cognosphere.
