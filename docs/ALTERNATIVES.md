# Alternatives and positioning

Istaroth is one of several independent Genshin Impact desktop companion tools. This comparison is based on the public project descriptions checked on **2026-11-02**, not on hands-on benchmark tests.

| Project | Primary emphasis | Where Istaroth differs |
|---|---|---|
| [Genshin Widget](https://github.com/Naguroka/GenshinWidget) | Configurable Windows/Linux PyQt5 account widget with Resin and HoYoLAB data | Istaroth centers a two-mode Windows experience with three separately customizable wallpaper areas and themed Style gallery |
| [SilentSelene](https://github.com/Grabacr07/SilentSelene) | Lightweight Windows 11 Resin timer with manual/automatic input and notification | Istaroth includes broader appearance controls, mini/full mode and HoYoLAB information panels |
| [Paimon browser extension](https://github.com/daidr/paimon-webext) | Browser-based Genshin account information and alerts | Istaroth is a Windows desktop application rather than a browser add-on |
| [Genshin Real-Time Notes](https://github.com/Beastwick18/genshin-real-time-notes) | Multi-game PC system-tray real-time notes | Istaroth focuses on desktop visual customization and widget appearance |
| [Genshin Impact Expedition Tracker](https://github.com/sonictriplex/genshin-expedition-tracker) | Expeditions and broader personal tracking/planning | Istaroth emphasizes automated HoYoLAB Resin tracking and themed desktop widgets |

Istaroth is **not** inherently faster, more secure or more feature-complete than these alternatives. It currently has an unsigned setup executable and an unofficial API dependency; users should choose according to their platform, preferred display mode, sign-in trust model and tolerance for third-party apps.

## Why use Istaroth?

- Floating Mini Widget **and** full desktop dashboard, with preserved per-mode appearance.
- Three independent wallpaper areas with live previews, not one shared app background.
- Nine named region-inspired themes in the Style gallery.
- Local session storage and no Istaroth-operated analytics service in the current release.
- Free open source code, public build documentation, privacy and security disclosures.

## Why choose something else?

- You prefer a browser extension with no new desktop installer.
- You require a code-signed installer or an independent security audit.
- You use macOS/Linux, which are not supported by the current Windows 1.0 release.
- You want expedition planning or resource calculators rather than a Resin-focused widget.
